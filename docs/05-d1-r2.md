# 05 — D1 Database & R2 Storage

## Overview

The Wasabi backend uses **Cloudflare D1** (SQLite) for structured data and **Cloudflare R2** for file/document storage. All operations go through the Cloudflare Worker API, accessed via `src/lib/api.js`.

---

## D1 Database Operations

### Health & Init

| Function | Endpoint | Purpose |
|----------|----------|---------|
| `checkHealth()` | `GET /health` | Worker health check |
| `initDatabase()` | `POST /init` | Initialize D1 tables |
| `factoryReset()` | `POST /factory-reset` | Drop and recreate all tables |

### Connections (Key-Value Store)

| Function | Endpoint | Purpose |
|----------|----------|---------|
| `getConnections()` | `GET /connections` | List all saved connections |
| `setConnection(key, value, metadata)` | `POST /connections` | Save a connection (Notion key, etc.) |
| `deleteConnection(key)` | `DELETE /connections/{key}` | Remove a connection |

### Page Configs

| Function | Endpoint | Purpose |
|----------|----------|---------|
| `listPages()` | `GET /pages` | List all page configs |
| `createPageConfig(config)` | `POST /pages` | Create new page |
| `getPageConfig(id)` | `GET /pages/{id}` | Get single page config |
| `updatePageConfig(id, updates)` | `PATCH /pages/{id}` | Update page config |
| `deletePageConfig(id)` | `DELETE /pages/{id}` | Delete page config |

### Table Schema

| Function | Endpoint | Purpose |
|----------|----------|---------|
| `getTableSchema(id)` | `GET /pages/{id}/schema` | Get column definitions |
| `updateTableSchema(id, columns)` | `PATCH /pages/{id}/schema` | Update columns |

### Table Rows (CRUD)

| Function | Endpoint | Purpose |
|----------|----------|---------|
| `listRows(tableId, {limit, offset, archived})` | `GET /tables/{id}/rows` | List rows with pagination |
| `createRows(tableId, rows)` | `POST /tables/{id}/rows` | Batch create rows |
| `updateRow(tableId, rowId, updates)` | `PATCH /tables/{id}/rows/{rowId}` | Update row (merge_cells by default) |
| `deleteRow(tableId, rowId)` | `DELETE /tables/{id}/rows/{rowId}` | Delete row |
| `queryTable(tableId, {filters, sorts, limit, offset})` | `POST /tables/{id}/query` | Advanced query with filters/sorts |

## R2 Storage

### File Operations

| Function | Endpoint | Purpose |
|----------|----------|---------|
| `uploadFile(file, pageId)` | `POST /files` | Upload file (multipart) |
| `listFiles(pageId)` | `GET /files?page_id={id}` | List files for page |
| `getFileUrl(fileId)` | computed URL | Get file download URL |
| `deleteFile(fileId)` | `DELETE /files/{id}` | Delete file |

### Document Storage

| Function | Endpoint | Purpose |
|----------|----------|---------|
| `getDocument(id)` | `GET /docs/{id}` | Get document content |
| `saveDocument(id, content)` | `PUT /docs/{id}` | Save document |
| `updateDocBlocks(id, updates)` | `PATCH /docs/{id}/blocks` | Partial block update |
| `exportDocNotion(id)` | `GET /docs/{id}/export/notion` | Export to Notion format |

### Sheets (D1 + R2)

| Function | Endpoint | Purpose |
|----------|----------|---------|
| `getSheet(id)` | `GET /sheets/{id}` | Get spreadsheet data |
| `updateSheet(id, updates)` | `PATCH /sheets/{id}` | Update cells |
| `sheetFormula(id, fn, args, target)` | `POST /sheets/{id}/formula` | Execute formula |
| `sheetStructure(id, action, index)` | `POST /sheets/{id}/structure` | Add/remove rows/cols |
| `resizeSheet(id, dimensions)` | `POST /sheets/{id}/resize` | Resize grid |
